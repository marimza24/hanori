Política de Privacidad

Última actualización: 12 de agosto de 2026

Esta Política de Privacidad explica cómo Hanori trata la información relacionada con el uso de la aplicación móvil y del sitio web.

1. Sobre Hanori

Hanori es una aplicación educativa destinada al aprendizaje y la práctica de vocabulario coreano mediante actividades interactivas.

2. Aplicación móvil Hanori

La aplicación móvil de Hanori no requiere la creación de una cuenta ni el inicio de sesión.

La aplicación no solicita directamente datos como nombre, dirección de correo electrónico, número de teléfono o ubicación.

El progreso de aprendizaje, las respuestas y las preferencias de uso de la aplicación se almacenan localmente en el dispositivo del usuario.

Estos datos de progreso no se envían a un servidor de Hanori.

3. Notificaciones

Hanori puede utilizar notificaciones locales para ofrecer recordatorios relacionados con la práctica del vocabulario.

El usuario puede permitir, bloquear o desactivar estas notificaciones desde la configuración de su dispositivo.

4. Sitio web de Hanori

El sitio web de Hanori ofrece información sobre la aplicación y una versión de demostración del Rosco Hangul.

El sitio utiliza Google Analytics 4 para obtener estadísticas generales sobre la utilización de la página y comprender mejor cómo se utiliza el sitio.

5. Google Analytics

Google Analytics puede recopilar información técnica y estadística, entre ella:

  • estadísticas de sesiones y visitas al sitio;
  • información aproximada sobre la ubicación geográfica;
  • información sobre el navegador y el tipo de dispositivo utilizado;
  • páginas visitadas e interacciones generales con el sitio;
  • un identificador de cliente asociado a una cookie de Analytics.

Importante: Google Analytics se utiliza en el sitio web de Hanori. Esto no significa que la aplicación móvil de Hanori utilice actualmente Google Analytics.

Google puede procesar información técnica, incluida la dirección IP, para funciones necesarias del servicio y para obtener información geográfica aproximada.

Hanori no utiliza Google Analytics con el propósito de identificar personalmente a quienes visitan el sitio.

6. Cookies

Google Analytics puede utilizar cookies propias, incluida la cookie _ga, para distinguir usuarios y sesiones y generar estadísticas de uso del sitio.

7. Publicidad

La aplicación Hanori no contiene anuncios publicitarios.

El sitio web tampoco muestra publicidad de terceros.

8. Venta de datos personales

Hanori no vende datos personales de sus usuarios.

9. Menores de edad

Hanori es una herramienta educativa. La aplicación no está diseñada para solicitar deliberadamente información personal a menores de edad.

10. Servicios externos

El sitio web se encuentra alojado mediante servicios de infraestructura web y utiliza Google Analytics para la medición de estadísticas de navegación.

11. Cambios en esta política

Esta Política de Privacidad podrá actualizarse en el futuro si Hanori incorpora nuevas funciones, servicios o herramientas que modifiquen el tratamiento de información.

La fecha de la última actualización se indicará al comienzo de esta página.

Política de Privacidad

Última actualización: 10 de agosto de 2026

Hanori es una aplicación educativa diseñada para aprender y practicar vocabulario coreano de una manera sencilla, visual e interactiva.

Datos personales

Hanori no solicita, recopila, almacena ni comparte datos personales de los usuarios.

La aplicación no requiere crear una cuenta, iniciar sesión ni proporcionar información personal como nombre, correo electrónico, número de teléfono o ubicación.

Datos almacenados en el dispositivo

Hanori guarda localmente en el dispositivo información necesaria para el funcionamiento de la aplicación, como el progreso de aprendizaje, palabras practicadas, respuestas y preferencias relacionadas con la práctica.

Esta información permanece en el dispositivo del usuario y no se transmite a servidores externos.

Notificaciones

Hanori puede utilizar el sistema de notificaciones del dispositivo para mostrar recordatorios relacionados con la práctica.

Los usuarios pueden administrar o desactivar estas notificaciones desde la configuración de su dispositivo.

Servicios de terceros

Hanori no utiliza servicios de publicidad, herramientas de analítica, sistemas de seguimiento de usuarios ni servicios externos destinados a recopilar datos personales.

Compartición de datos

Hanori no vende, comparte ni transfiere datos personales a terceros.

Privacidad de menores

Hanori no recopila intencionadamente información personal de menores ni de otros usuarios.

Cambios en esta política

Esta política podrá actualizarse si futuras versiones de Hanori incorporan funcionalidades que modifiquen la forma en que se gestionan los datos.

Contacto

Para consultas relacionadas con esta política de privacidad o con Hanori, puedes escribir a:

hanori@outlook.com.ar
